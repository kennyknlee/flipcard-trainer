# FlipCard Trainer / 啤牌記憶訓練器

A standalone mobile-friendly card-flip study app.

Live site:

https://kennyknlee.github.io/flipcard-trainer/

## MVP features

- Default 地支十二時辰 deck
- Covered → question → answer card cycle
- Shuffle and reset
- Mark 識 / 唔識 / 再溫
- localStorage persistence
- JSON import/export
